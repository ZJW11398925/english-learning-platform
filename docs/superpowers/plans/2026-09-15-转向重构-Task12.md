## 背景一句话

人工契约级验收挂起（旧设计假设被推翻）。新形态：**GitHub Pages 静态前端 + 访问者自带 API Key（localStorage）+ 浏览器直连模型 API（CORS 已实测放行）+ TTS 示范替代跟读 + 相册导入**。服务端代理（server/）退役。

## Task 12A · 前端直连 + Key 管理（先做，风险最高）

**目标**：识物与造句两条链路的模型调用从「本机服务端代理」改为「浏览器直连 `https://api.deepseek.com`」，API Key 由访问者在页面上填入并存 localStorage（键位约定见下），无 Key 时给引导页而不是白屏。

**范围**：
- 新增 `web/units/keyring.mjs`：Key 的存取与校验（localStorage 键 `elp.apiKey`；写入前做非空 + `sk-` 前缀的轻校验；提供注入点以便测试）
- 新增设置入口（word/ready 屏可达）：填 Key、显示当前是否已配置（不回显明文）、清除
- `web/units/recognize.mjs` / `units/compose.mjs`（或其传输层）：请求改直连 `/v1/chat/completions`；把 server/ 里 `recognize-upstream.mjs` / `feedback-upstream.mjs` 的**提示词组装与响应解析**移植到客户端；客户端校验（`validateFeedback` 等）口径**一字不动**
- 场景词包（手选词表）若由服务端下发，改为 `web/` 下静态 JSON
- 事件口径不变：`recognize_ok.latencyMs` 仍取**取到词那一次**的耗时（直连侧用 `performance.now()` 自测，服务端没给的数不发明——现在没有服务端了，这个数就是客户端实测值，含义变化要在代码注释里写清）
- server/ 代码**本任务不删**（12C 处理），但客户端不再调用它
- 无 Key 访问者：ready 屏给引导文案（怎么拿 Key、为什么需要、存哪了），不闪不崩

**验收**（VAL 载体在 dmcp）：
1. 全量 `node --test` 绿（新增用例覆盖：Key 存取/轻校验/清除；直连请求带 Authorization；响应解析与校验口径与旧服务端信封逐字段一致；无 Key 时引导路径；401/429/网络错误三类失败的降级路径——401 引导回设置页）
2. 变异探针全绿（含既有变体无回退；新模块带变体——先确认模块能过探针语法门，见台账「export from 再导出」教训）
3. 客户端事件流字段形状不变（export.mjs 的 summarize 在新事件流上口径一致）

**红线**：
- 三份 digest 绑定文档（spec / 旧计划 / 真机清单）**一字不动**
- 不新增运行时依赖（保持零依赖 ES Modules）
- 不碰 `.env` / 真实 Key（测试用假 Key；公开仓库的测试夹具里只允许合成钥匙）
- TDD：先 RED 用例再实现；探针跑前冻结工作树

## Task 12B · 相册导入 + TTS 示范（依赖 12A 的直连传输）

**目标**：
1. 拍照输入源增加「从相册选图」（`<input type="file" accept="image/*">`），走同一条帧质检 → 识物链路；拍照按钮保留，两个入口并列
2. 跟读改造：`speechSynthesis` 播目标词示范音（en-US 语音，选不到就任何英文声）；界面从「念出这个词（自动判定）」变为「听示范 → 自己念 → 自评打勾/跳过」；SpeechRecognition 判定路径与 `speech_unsupported`/`reading_missed`/`reading_done` 事件**退役**（事件类型保留在 schema 里不删，只是不再产生；诊断页对应表格保留历史数据展示）

**验收**：全量测试绿（相册图的质检/识别用例；TTS 注入点用例；事件退役后诊断页渲染不崩）；探针绿。

## Task 12C · server/ 退役 + Pages 上线（依赖 12A/12B）

**目标**：
1. 删除 `server/` 与 `.env` 依赖（本地开发用任意静态服务器，README 写清 `npx serve .` 之类的一条命令）

**验收**：仓库根无 server/ 残留引用（grep 清零）；线上 URL 可用；无 Key 引导路径在线上可用。
